# External Reference Repositories

This folder contains reference implementations and libraries used in the Jawir OS project.

## Contents

### 1. **cookbook** (Google Gemini API Examples)
- Official Google Gemini API cookbook
- Contains examples for:
  - Agents & Function Calling
  - Video Analysis (Classification, Summarization, Event Recognition)
  - Multimodal AI applications
- Used for: Gemini integration patterns and best practices

### 2. **electron-vite-react** (Electron Boilerplate)
- Modern Electron + Vite + React template
- TypeScript support with hot reload
- Used as base architecture for Jawir OS desktop app

### 3. **go-whatsapp-web-multidevice** (WhatsApp Integration)
- Go-based WhatsApp Web multidevice API
- RESTful API for WhatsApp automation
- Used for: WhatsApp messaging features in Jawir OS

### 4. **KiCAD-MCP-Server** (KiCad MCP Integration)
- Model Context Protocol server for KiCad
- AI-assisted PCB design capabilities
- Used for: KiCad schematic generation features

### 5. **live-node-starter** (Deepgram Real-time Speech)
- Deepgram live transcription starter
- Real-time speech-to-text implementation
- Used for: Voice control and wake word detection

### 6. **open-interpreter** (Computer Control AI)
- Open Interpreter project
- Autonomous code execution and computer control
- Used for: Advanced mode (Mode Bebas) in Jawir OS

### 7. **openWakeWord** (Wake Word Detection)
- Open-source wake word detection
- Lightweight on-device activation
- Used for: "Jawir" wake word implementation

### 8. **playwright-mcp** (Browser Automation)
- Model Context Protocol for Playwright
- Browser automation via AI
- Used for: Web scraping and browser control features

## Usage in Jawir OS

These repositories serve as:
- **Reference implementations** for integrating with external services
- **Code examples** for complex features (voice, AI, automation)
- **Library sources** for understanding API patterns
- **Documentation** for best practices

## Notes

- Files are copied without `.git`, `node_modules`, and build artifacts
- Original repositories may have been updated since copy
- Check original repo links for latest versions and updates
